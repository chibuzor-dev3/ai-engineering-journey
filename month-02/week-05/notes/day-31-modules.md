# 1. What is a JavaScript Module?

A JavaScript module is a JavaScript file that contains code that can be shared with other JavaScript files.

Instead of putting everything into one large JavaScript file, we can divide our application into smaller files.

Example:

```text
project/
├── main.js
├── math.js
├── user.js
