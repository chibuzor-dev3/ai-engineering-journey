# Day 17 - JavaScript Operators

## What I Learned

- Arithmetic operators perform calculations.
- + adds numbers.
- - subtracts numbers.
- * multiplies numbers.
- / divides numbers.
- % returns the remainder after division.
- Assignment operators change the value of variables.
- += adds to a variable.
- -= subtracts from a variable.
- ++ increases a variable by 1.
- -- decreases a variable by 1.

## Practice

Today I used operators to solve real-world problems like calculating shopping totals and updating the balance in a wallet.

## Reflection

Operators make JavaScript useful because they allow programs to perform calculations and update data automatically.
